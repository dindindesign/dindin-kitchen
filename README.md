A premium, single-file HTML template for restaurants, chefs, cafés, and modern dining brands — built with **Tailwind CSS** (compiled via Tailwind CLI) and **Alpine.js** (CDN).

## Overview

Dindin Kitchen is an editorial-style restaurant website template designed around a warm, ink-and-paprika color system with Fraunces/Work Sans/JetBrains Mono typography. It ships as a **single `.html` file**, making it easy to preview, customize, or drop straight into any static host, CMS, or Blogger-style platform.

## Features

- **Fully Responsive** — Adapts cleanly across mobile, tablet, and desktop breakpoints.
- **Sticky Header** — Transitions from transparent to solid on scroll.
- **Click-to-Open Nav Dropdown** — Accessible "Menu" dropdown with outside-click and `Escape` handling.
- **Interactive Menu Tabs** — Category filtering (Starters / Mains / Desserts / Drinks) powered by Alpine.js.
- **Signature Dot-Leader Menu Rows** — Classic restaurant-ticket styling connecting dish names to prices.
- **Reservation Form** — Includes a custom Headless-UI-style dropdown for party size selection.
- **Mobile Navigation Panel** — Slide-down menu with `x-cloak` to prevent flash-of-unstyled-content.
- **SEO-Ready** — Meta description, Open Graph, Twitter Card, canonical URL, and JSON-LD `Restaurant` structured data.
- **Accessible Markup** — Semantic HTML5, ARIA attributes, and visible keyboard focus states.
- **Footer Credit** — "Designed by Dindin Design" link included.

## Tech Stack

| Layer         | Library                                                                  |
| ------------- | ------------------------------------------------------------------------ |
| Styling       | [Tailwind CSS](https://tailwindcss.com/) (compiled via **Tailwind CLI**) |
| Interactivity | [Alpine.js](https://alpinejs.dev/) (CDN)                                 |
| Icons         | Inline SVG (no icon library dependency)                                  |
| Fonts         | Google Fonts — Fraunces, Work Sans, JetBrains Mono                       |
| Images        | [Unsplash](https://unsplash.com/) (hotlinked, royalty-free)              |

This project uses the official **Tailwind CLI** to compile a static stylesheet, rather than the Play CDN build — the CDN build is intended for quick demos only and is [not recommended for production](https://tailwindcss.com/docs/installation/play-cdn). Alpine.js remains CDN-based, as it has no build requirement.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or later

### 1. Install Tailwind CSS

Install `tailwindcss` and `@tailwindcss/cli` via npm.

```bash
npm install tailwindcss @tailwindcss/cli
```

### 2. Import Tailwind in your CSS

Add the `@import` directive to your main stylesheet.

```css
/* src/input.css */
@import "tailwindcss";
```

### 3. Run the Tailwind CLI build

Scan the project's source files and compile the output stylesheet. Use `--watch` during development to rebuild automatically on save.

```bash
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
```

For a production build, omit `--watch` and add `--minify`:

```bash
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --minify
```

### 4. Link the compiled stylesheet

Reference the compiled `output.css` file in the `<head>` of `dindin-kitchen.html` in place of the Play CDN `<script>` tag:

```html
<link href="./src/output.css" rel="stylesheet" />
```

### 5. Open the project

```bash
git clone https://github.com/your-username/dindin-kitchen.git
cd dindin-kitchen
npm install
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
open dindin-kitchen.html   # or serve the folder with any static server
```

## Customization

- **Colors & Theme** — Define custom colors (`ink`, `paper`, `paprika`, `saffron`, `sage`) and fonts as CSS variables in an `@theme` block inside `src/input.css`, then re-run the CLI build. See [Theme variables](https://tailwindcss.com/docs/theme) in the Tailwind docs.
- **Fonts** — Swap the Google Fonts `<link>` in `dindin-kitchen.html` and update the corresponding `--font-*` variables in `src/input.css`.
- **Content** — Replace placeholder text, menu items, prices, and reservation details directly in the corresponding `<section>` blocks.
- **Images** — Swap any Unsplash URL for your own hosted images; update the `alt` text accordingly for SEO and accessibility.
- **Reservation Form** — The form currently resets on submit for demo purposes; connect the `<form>` element to your booking backend or a service like Formspree.
